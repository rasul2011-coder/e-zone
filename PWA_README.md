# PWA (Progressive Web App) - English Zone

## ✅ Что реализовано:

### 1. **Service Worker**
- Автоматическая генерация service worker с помощью `next-pwa`
- Кэширование статических ресурсов (JS, CSS, изображения, шрифты)
- Оффлайн поддержка для главной страницы и статического контента
- Исключение платежных и авторизационных роутов из кэша

### 2. **Manifest.json**
- Название приложения: "English Zone - Языковой центр"
- Короткое имя: "EnglishZone"
- Цвета темы: оранжевый (#f97316) и тёмно-синий (#0f1d35)
- Режим отображения: standalone (как нативное приложение)
- Иконки в форматах 72x72 до 512x512

### 3. **Иконки приложения**
- Сгенерированы иконки в 8 размерах (72, 96, 128, 144, 152, 192, 384, 512)
- Логотип: "EnglishZone" с оранжевым акцентом
- SVG и PNG форматы
- Поддержка Apple Touch Icon

### 4. **Оффлайн страница**
- Красивая страница `/offline` при отсутствии интернета
- Кнопка обновления страницы
- Ссылка на главную
- Список доступного оффлайн контента

### 5. **Мета-теги PWA**
- Theme color для Android
- Apple Web App мета-теги для iOS
- Viewport настройки
- Manifest link

## 📦 Установленные пакеты:

```bash
npm install next-pwa
npm install --save-dev sharp-cli
```

## 🚀 Использование:

### Разработка:
```bash
npm run dev
```
Service Worker отключен в dev режиме для удобства.

### Production build:
```bash
npm run build
npm start
```

### Проверка PWA:
1. Откройте приложение в браузере
2. Chrome DevTools → Application → Manifest
3. Chrome DevTools → Application → Service Workers
4. Lighthouse → Progressive Web App audit

## 📱 Установка на устройство:

### Android:
1. Откройте сайт в Chrome
2. Нажмите "⋮" → "Установить приложение"
3. Приложение появится на главном экране

### iOS:
1. Откройте сайт в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой)
3. Прокрутите и выберите "На экран «Домой»"

## 🔧 Настройка кэширования:

Все настройки в `next.config.ts`:

```typescript
runtimeCaching: [
  // Шрифты - кэш навсегда
  // Изображения - кэш 24 часа
  // API (кроме платежей) - кэш 1 час
  // Страницы - Network First с fallback
]
```

### Исключено из кэша:
- `/api/finik/*` - платежи
- `/api/auth/*` - авторизация

## 📝 Кастомизация иконок:

Для создания собственных иконок:

1. Создайте SVG логотип 512x512
2. Замените `public/icon.svg`
3. Запустите:
```bash
node scripts/generate-icons.js
```

Или используйте онлайн генератор:
- https://realfavicongenerator.net/
- https://favicon.io/

## 🔒 Безопасность:

- Service Worker работает только через HTTPS
- Платежные роуты исключены из кэша
- Sensitive данные не кэшируются

## 🌐 Поддержка браузеров:

- ✅ Chrome/Edge (полная поддержка)
- ✅ Firefox (полная поддержка)
- ⚠️ Safari (ограниченная поддержка, работает как закладка)
